# Deployment Guide

## Prerequisites

| Tool      | Minimum Version | Check Command         |
|-----------|----------------|-----------------------|
| Git       | 2.x            | `git --version`       |
| Terraform | 1.6.x          | `terraform -version`  |
| AWS CLI   | 2.x            | `aws --version`       |
| Docker    | 24.x           | `docker --version`    |
| Python    | 3.10+          | `python3 --version`   |

## Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/terraform-aws-devops-platform.git
cd terraform-aws-devops-platform
